# Xiaomi Redmi 15C (Dew) — Patch Cert 2026

Registro de compatibilidad para **Xiaomi Redmi 15C (`dew`)**: compatible con **HyperOS 1, 2 y 3**, sin importar la fecha del parche de seguridad, con **Patch Cert 2026 exitoso**.

---

## Ficha técnica del equipo de prueba

| Parámetro | Detalle |
| :--- | :--- |
| **Marca / Modelo comercial** | Xiaomi Redmi 15C |
| **Codename (Product / Board)** | `dew` |
| **Código de modelo** | `25078RA3EE` |
| **Región** | `EEA` |
| **Plataforma / SoC** | MediaTek (`MT6768` / `MT6769`) |
| **Sistema Operativo** | Android 15 (SDK 35) |
| **Versión de Software** | `OS2.0.212.0.VBNEUXM` |
| **Parche de seguridad** | `2025-08-01` |
| **Estado del Bootloader** | `locked` |
| **Acceso Root (prueba)** | `DFTSU: 1.3 (Kernel)` / SELinux `Permissive` |

---

## Configuración en herramienta

* **Herramienta:** DFT Pro `v9.0.0`
* **Ruta:** `Xiaomi` → `Adb Services` → `Service`
* **Plataforma seleccionada:** `MTK`
* **Opción activada:** `Patch Cert 2026`
